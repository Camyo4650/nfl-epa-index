# Web interface

Docker Compose serves the site with nginx and proxies `/api` to the .NET API. Outside Docker, the .NET API serves the site directly; the standalone Node static server does not proxy API requests. See the [project setup](../README.md) for prerequisites, startup, data definitions, and API details.

The rankings and movement views share season, week, and EPA metric selections when navigating between them. Both show the latest entered week and refresh status. Team logos and colors come from nflverse; abbreviated badges remain visible if a logo cannot load. Teams with no qualifying plays are omitted until data is available. `src/data.ts` is retained only as a fixture for the existing sample-data tests; the live interface does not use it.

The Playoffs page shows a provisional conference picture for the selected completed week. Division and wild-card tiebreakers use head-to-head, division and conference records, common games, strength of victory, and strength of schedule when applicable. Later tiebreakers fall back to team abbreviations. The same rules apply to the historical and simulated game outcomes. Its combined EPA-per-play simulation model is fitted to historical games, but probabilities (including 0% and 100%) remain estimates, not official results or clinching proofs. Clinched and eliminated labels use conservative record bounds until the regular season ends. Once a complete postseason schedule is available, final-week labels and 0%/100% values reflect actual postseason qualifiers; ordering within groups remains provisional. If that schedule is incomplete, labels remain based on record bounds and some teams may be undetermined. A complete regular-season schedule and all 32 teams' EPA ratings are required.

The first request for a playoff picture runs 100,000 simulations in the background. The page polls until the result is available and displays the percentage of simulations completed. It shows a waiting message while checking the cache or waiting for a job to start; the percentage may reset if the underlying snapshot changes during a run. Results are cached in SQLite and regenerated when their inputs or model version change.

The 2022 Buffalo–Cincinnati game was canceled and is not included in the schedule or simulations, including historical views before the cancellation.

On the rankings page, Rank is shown by default and reflects each team's position in the selected column across all teams, unaffected by sort direction, conference, or search filters. Better records, points for, net points, and changes rank higher; fewer points allowed and lower defensive EPA rank higher. Other EPA metrics rank higher values first. Rank, previous rank, and SOS rank use lower values first; text columns use alphabetical order. Ties use EPA rank as a tiebreaker, and unavailable values come last. Selecting Rank sorts by the selected metric's EPA ranking; Previous rank and Change always refer to EPA rankings.

Run `npm ci` and `npm run build` in this directory before starting the .NET server locally. The TypeScript compiler emits browser modules to `dist`; rebuild after changes. Docker builds the frontend automatically. Run `npm test` to build and run the frontend unit tests. On narrow screens, scroll the table and movement chart horizontally.
