PLAYOFF PROBABILITY MODULE STRUCTURE
=====================================

WARNING: The prototype does not implement NFL tiebreakers or reliable
clinching, and the integration and validation claims below are inaccurate.

playoff_probability.py (459 lines)
├── Imports & Setup
│   ├── random, collections, typing, dataclasses, math
│   └── No external dependencies beyond Python stdlib
│
├── Data Classes
│   ├── TeamRecord(team_id, wins, losses, ties, division, conference)
│   │   ├── Properties: games_played, win_pct
│   │   └── Used by: Both simulators for state tracking
│   │
│   └── GameOutcome(home_team, away_team, home_wins, tie)
│       └── Used by: MonteCarloSimulator.simulate_game()
│
├── MonteCarloSimulator (Class)
│   ├── __init__(num_simulations=10000)
│   │
│   ├── epa_to_win_probability(home_epa, away_epa, home_field_advantage=2.5)
│   │   ├── Logistic regression model: P = 1/(1 + exp(-k*epa_diff))
│   │   ├── k ≈ 0.03 (calibrated to NFL data)
│   │   └── Returns: float (0-1) win probability
│   │
│   ├── simulate_game(home_team, away_team, epa_ratings, seed=None)
│   │   ├── Calculates win probability
│   │   ├── Considers ~0.2% tie rate
│   │   └── Returns: GameOutcome
│   │
│   ├── simulate_season(records, schedule, epa_ratings)
│   │   ├── Simulates all remaining games
│   │   ├── Updates records progressively
│   │   └── Returns: Dict[team_id, TeamRecord]
│   │
│   ├── calculate_playoff_odds(records, schedule, epa_ratings, playoff_teams_per_conference=7)
│   │   ├── Main entry point
│   │   ├── Runs N simulations
│   │   ├── Determines playoff teams each simulation
│   │   └── Returns: Dict[team_id, float] playoff probability
│   │
│   └── _get_playoff_teams(records, playoff_teams_per_conference)
│       ├── Static method
│       ├── Implements NFL playoff selection rules
│       ├── Division winners (up to 4 per conference)
│       ├── Wild cards (remaining spots by win %)
│       └── Returns: set of playoff team IDs
│
├── DeterministicPlayoffAnalyzer (Class)
│   ├── __init__()
│   │
│   ├── max_wins(record, games_remaining)
│   │   ├── Static method
│   │   └── Returns: int max possible wins
│   │
│   ├── min_wins(record)
│   │   ├── Static method
│   │   └── Returns: int (current wins)
│   │
│   ├── is_mathematically_eliminated(team_record, other_records, team_games_remaining, other_games_remaining)
│   │   ├── Checks if max wins < 7th place team's minimum wins
│   │   ├── Accounts for other teams' schedules
│   │   └── Returns: bool
│   │
│   ├── is_mathematically_locked(team_record, other_records, team_games_remaining, other_games_remaining)
│   │   ├── Checks if min wins > number of teams that can pass
│   │   ├── Counts teams with possible max > min wins
│   │   ├── Locked if <= 6 teams can pass
│   │   └── Returns: bool
│   │
│   └── analyze_playoff_status(records, games_remaining)
│       ├── Analyzes all teams
│       ├── Returns: Dict[team_id, status_string]
│       │   ├── "locked_in": mathematically in playoffs
│       │   ├── "eliminated": mathematically out
│       │   └── "contention": still possible
│       └── Used by: API endpoints, reports
│
└── Helper Functions
    ├── calculate_remaining_schedule(all_games, current_week, week_cutoff=18)
    │   ├── Filters games after current_week
    │   ├── Only returns games with no score yet
    │   └── Returns: List[(home_team, away_team)]
    │
    ├── extract_records_at_week(season_data, week)
    │   ├── Pulls record data from season JSON
    │   ├── Creates TeamRecord objects
    │   └── Returns: Dict[team_id, TeamRecord]
    │
    └── extract_epa_ratings(season_data, week)
        ├── Pulls combined EPA from season JSON
        └── Returns: Dict[team_id, float EPA rating]
